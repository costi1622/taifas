IMPORTANT DESPRE GITHUB
Interfata GitHub nu extrage automat un ZIP incarcat ca fisier in repository. ZIP-ul nu poate fi incarcat singur si aplicat automat fara un workflow GitHub Actions preconfigurat cu permisiuni de scriere. Acest pachet este un patch cu cai corecte, nu o arhiva completa a aplicatiei.
